# 学习 Conductor

<section class="integration-hero integration-hero--workflow" aria-label="Recommended: Orkes Academy" markdown="1">

## 推荐：Orkes Academy

[Orkes Academy](https://orkes.io/academy) 提供免费、动手实践的课程，带你从第一个工作流一路进阶到生产级模式，完成后可获得可分享的证书。如果你更偏好结构化的课程，而不是自己拼凑文档，就从这里开始。

</section>

在运行了第一个工作流或智能体之后，以下是进一步深入的路径。

## 基础知识

- [使用 Conductor 入门](../quickstart/index.md) — 选择与你工作方式匹配的路径，从 AI 智能体辅助到 SDK 优先。
- [编写你的第一个工作流和工作者](../quickstart/first-worker.md)，或[不写代码、从 JSON 运行工作流](../quickstart/first-workflow.md)。
- [运行你的第一个智能体](../quickstart/first-agent.md)，或通过[框架智能体快速入门](../quickstart/framework-agents.md)接入已有的智能体。

## 通过示例学习

**设计模式** 中的每个条目都是一个完整、可运行的示例：

- [工作流模式](../devguide/cookbook/index.md) — 编排、并行、补偿事务（Saga）、超时、定时调度。
- [智能体模式与配方](../devguide/ai/cookbook/index.md) — RAG、工具调用、交接、护栏、人在回路。
