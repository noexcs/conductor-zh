# SDKs

Conductor 为七种语言提供了官方 SDK。每个 SDK 都支持编写工作者（worker）、以代码定义工作流，并从你的应用中调用 Conductor API。下面每个 SDK 都有独立的参考页面，涵盖安装、工作者配置和可运行的示例。如果你是 Conductor 的新手，请先从[快速入门](../../quickstart/index.md)中的快速开始教程入手，然后再回到这里查看你所用语言的详细文档。

<a href="python-sdk.html" class="sdk-card"><div class="sdk-icon sdk-python" aria-hidden="true"></div><div class="sdk-info"><h3>Python</h3><p>基于装饰器的任务定义、异步支持和工作流管理。</p></div><span class="sdk-arrow">→</span></a>
<a href="go-sdk.html" class="sdk-card"><div class="sdk-icon sdk-go" aria-hidden="true"></div><div class="sdk-info"><h3>Go</h3><p>类型安全的任务定义、基于结构体的输入输出和并发工作者执行。</p></div><span class="sdk-arrow">→</span></a>

<a href="csharp-sdk.html" class="sdk-card"><div class="sdk-icon sdk-csharp" aria-hidden="true"></div><div class="sdk-info"><h3>C# / .NET</h3><p>依赖注入、async/await 模式和 NuGet 软件包。</p></div><span class="sdk-arrow">→</span></a>
<a href="ruby-sdk.html" class="sdk-card"><div class="sdk-icon sdk-ruby" aria-hidden="true"></div><div class="sdk-info"><h3>Ruby</h3><p>地道的 Ruby 风格任务定义和工作流管理。</p></div><span class="sdk-arrow">→</span></a>
<a href="rust-sdk.html" class="sdk-card"><div class="sdk-icon sdk-rust" aria-hidden="true"></div><div class="sdk-info"><h3>Rust</h3><p>类型安全的任务定义、异步运行时支持和零成本抽象。</p></div><span class="sdk-arrow">→</span></a>

所有 SDK 均为开源。Java、Python、JavaScript/TypeScript 和 C# 还支持共享的 [Conductor Agent](../../quickstart/first-agent.md) 实践旅程。
