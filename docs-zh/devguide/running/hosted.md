# 托管方案

## Orkes
[Orkes](https://orkes.io) 提供云托管的企业级 Conductor，让团队以最小的运维开销快速上手。除了与 Conductor OSS 完全兼容外，Orkes Conductor 还在此基础上添加了[更多功能](https://www.orkes.io/platform/conductor-oss-vs-orkes)。

通过 Orkes 使用 Conductor 的选项如下：

- Developer Edition（开发者版）
- Cloud Hosting Plans（云托管方案）

Orkes 还运营一个 [社区 Slack](https://join.slack.com/t/orkes-conductor/shared_invite/zt-3dpcskdyd-W895bJDm8psAV7viYG3jFA)，社区在其中讨论和分享 Conductor 的使用方法。

### Developer Edition
免费的 Orkes Conductor Developer Edition 可在 [developer.orkescloud.com](https://developer.orkescloud.com/) 获取。Developer Edition 包含 Orkes 的全部企业功能，包括可视化工作流编辑器、AI 编排套件、事件驱动连接器、人工介入任务等。你可以从 UI 或 API 创建并执行工作流。

### 云托管 Conductor
Orkes 在云端（AWS、Azure 和 GCP，以及私有云）提供多种托管 Conductor 集群选项，并由 Orkes 团队提供企业级支持。在此了解更多 [Orkes Cloud](https://orkes.io/cloud)。
